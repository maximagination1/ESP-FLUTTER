# ESP-FLUTTER Firmware 🦋

Official firmware for **ESP-FLUTTER**, an ESP32-powered bionic RC butterfly.

ESP-FLUTTER uses a XIAO ESP32-C3 and two digital servos to generate controllable flapping-wing
flight and can be controlled wirelessly using a smartphone or RC transmitter.

🎥 **Full Build Tutorial:** [YouTube link]
📁 **Project Files & BOM:** [Project link]

## Features

- ESP32-based wireless flight control
- Smartphone web interface
- RC transmitter support using ESP-NOW and CRSF (ELRS Receivers)
- Adjustable flapping frequency and amplitude
- Differential-amplitude steering
- Adjustable neutral/pitch angle
- Configurable servo parameters
- Experimental phone-tilt control

As Max gets more time, the remaining documentation and setup guide for ESP-FLUTTER Firmware will be eventually added.
For now, please refer to the video instructions and other files which already contain this information.
